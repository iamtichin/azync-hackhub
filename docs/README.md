## Quy tắc đọc claim

- Một final submission đã chạy live; các tình huống AI bổ sung dùng fixture cô lập.
- Phantom đã chạy live; Solflare extension chưa được kiểm thử đầy đủ.
- Project mẫu gồm source code và walkthrough tĩnh, chưa deploy.
- AI hỗ trợ đọc evidence và đặt câu hỏi; con người chấm điểm và chọn winner.
- Submission cNFT cùng winner cNFT xác nhận record của Azync, không chứng minh code của đội tự chạy on-chain.
